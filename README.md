Read and Process a Text File

Description

This Python project reads a text file and generates statistics such as the total number of lines, words, and characters.

Features

- Reads text using Python's "open()" function.
- Counts lines, words, and characters.
- Handles missing files using exception handling.
- Uses "with open()" to close the file automatically.

Requirements

- Python 3
- A text file named "input.txt"

How to Run

1. Save the program as "text_processor.py".
2. Create "input.txt" in the same folder.
3. Run the Python program.
4. View the generated statistics in the output.

Conclusion

This project demonstrates basic file handling, text processing, counting operations, and exception handling in Python.
